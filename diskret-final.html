📐 Теоремалар (P → Q)

• Converse (кері): Q → P
• Inverse (қарама-қарсы): ¬P → ¬Q
• Contrapositive: ¬Q → ¬P

🧩 PDNF vs PCNF (00, 01, 10, 11)

• PDNF (1-лер бойынша): 0 → ¬x, 1 → x; іші ∧, арасы ∨
• PCNF (0-дер бойынша): 0 → x, 1 → ¬x; іші ∨, арасы ∧
